# ealexisaraujo/homebrew-tap

Homebrew casks for apps by [Alexis Araujo](https://github.com/ealexisaraujo).

```bash
brew install --cask ealexisaraujo/tap/<cask>
```

| Cask | App |
| --- | --- |
| `agent-sounds-bar` | [Agent Sounds Bar](https://github.com/ealexisaraujo/agent-sounds-bar): menu bar control for the sounds your coding agents play |

Casks are updated by each app's release script. Please report problems in the app's own repository.
